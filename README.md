# 📋 하루 계획 — 타임박스 플래너

> **계획과 실행을 나란히 기록하는 하루 플래너.**
> 초보 전업투자자를 위해 만들었습니다. 왼쪽엔 **계획(PLAN)**, 오른쪽엔 **실제로 한 일(DONE)** 을
> 10분 단위로 칠해두면, 하루가 끝났을 때 "계획대로 살았는지"가 한눈에 보입니다.

## 무엇을 할 수 있나

| | |
|---|---|
| **PLAN / DONE 타임라인** | 한 행 = 1시간, 한 칸 = 10분. 드래그로 칠하고, 블록을 눌러 이름을 붙입니다. `→` 버튼으로 계획을 실행으로 통째로 복사. |
| **장 시간 표시** | 정규장(09:00–15:30)과 **애프터마켓(16:00–20:00)** 이 타임라인에 음영으로 겹쳐 보입니다. 지금 장 상태도 실시간 표시. |
| **Goal · Big 3** | 오늘의 목표와 "반드시 끝낼 3가지". |
| **프로젝트별 할 일** | 학습/일정 탭 아래 그룹을 만들고 체크. 할 일을 타임라인으로 **드래그**하면 바로 블록이 됩니다. 어제 미완료는 `↩` 로 가져오기. |
| **뽀모도로** | 집중 타이머가 끝나면 그 시간대가 DONE에 **자동 기록**됩니다. |
| **통계** | 주간/월간 공부시간 추이, 카테고리별 시간, **계획 대비 실천율**, 연속 기록. |
| **회고(K/P/T)** | 매일 Keep·Problem·Try 한 줄. 회고 탭에서 날짜별로 모아 봅니다. |
| **경제용어 노트** | 경제신문 읽다 모르는 말을 내 말로 정리하고 ★로 복습 표시. |
| **종목 리서치 메모** | 종목별로 "왜 샀는지"를 템플릿에 맞춰 기록. |

## 특징
- **설치 없음, 로그인 없음.** 브라우저만 있으면 됩니다.
- **내 기기에만 저장**(localStorage). 서버로 아무것도 보내지 않습니다.
- **오프라인 동작**(PWA). 폰에서 브라우저 메뉴 → "홈 화면에 추가" 하면 앱처럼 쓸 수 있어요.
- 백업이 필요하면 **설정 → 내보내기(JSON)**, 복구는 **가져오기**.
